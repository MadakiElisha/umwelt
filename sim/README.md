# sim

Gazebo worlds, PX4 configuration and launch files.

Target versions: PX4 v1.15 or newer, Gazebo Harmonic, ROS 2 Jazzy, with the Micro XRCE-DDS Agent bridging PX4 and ROS 2.

PX4 is not vendored here. Point `PX4_DIR` at your checkout if it is not in `~/PX4-Autopilot`. The exact PX4 tag this project is tested against will be recorded in this file once the first sim launch lands.
